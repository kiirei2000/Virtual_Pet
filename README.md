# 🐈 Floating Cat Rio

A virtual desktop cat that dances, yawns, eats, cries, and wanders around your screen like it owns the place 😼  
This animated assistant sits *on top of your desktop* and reacts to your interaction — with no window borders, buttons, or distractions.

---

## 🌟 Features

- 🎞️ **Fully animated** — uses GIFs to represent mood changes
- 💬 **Reacts to you**:
  - Click to make Rio dance
  - Ignore him too long? He gets bored or falls asleep 😴
  - Poke too many times? He cries and sulks 😿
- 🕹️ **Drag & drop** Rio anywhere on screen
- 🪄 **Borderless transparent window** that floats over your workspace
- 🎹 Global shortcut: `Alt + Shift + ~` to hide/show the cat

---

## 💻 How to Run

### 🐍 With Python:
1. Install dependencies:
   ```bash
   pip install pillow keyboard
2. Run the cat:
   ```bash
   python floating_cat.py
Without Python (EXE version):

Download the .exe from the Releases

1. Extract the zip
2. Make sure the assets/ folder is next to floating_cat.exe
3. Double-click the .exe to summon Rio!
