# 🎯 Whac-a-Rio
A rhythm-inspired reflex game featuring Rio, your chaotic cartoon cat 🐱💥  
Inspired by Whac-a-Mole and OSU, built in Python with tkinter!

---

## 🕹️ How to Play

- Cats randomly appear on your screen
- **Click them quickly** to earn points and make them cry (gently 😿)
- **Miss one?** Rio gets away and you lose points!
- Score higher, and Rio gets faster and harder to hit

---

## 🎮 Game Modes

- **Normal Mode** (default): classic windowed gameplay
- **Borderless Mode**: press `Alt + Shift + M` to toggle — cats spawn all over your desktop for a chaotic "floating pet" vibe!

---

## 📦 How to Run

### 🐍 With Python:
1. Install dependencies:
   ```bash
   pip install pillow keyboard
2. Run the game:
   ```bash
   python whac_a_rio.py
   ```
Without Python (Windows EXE):
Download the .exe from the Releases page

Unzip the file

Make sure the assets/ folder is in the same folder as whac-a-rio.exe

Double-click whac-a-rio.exe to start playing!
